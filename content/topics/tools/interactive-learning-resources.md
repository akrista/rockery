A curated list of interactive games, visualizers, and browser-based sandboxes for learning programming, Git, SQL, regex, shell, CSS, and DevOps.

## Git & Version Control

- **[Learn Git Branching](https://learngitbranching.js.org/)**: Interactive visual sandbox and step-by-step tutorial for mastering Git branching, merging, rebasing, and cherry-picking.
- **[Oh My Git!](https://ohmygit.org/)**: Open-source game that visualizes Git repositories as cards and graphs to make Git concepts intuitive and visual.

## Shell & Command Line

- **[explainshell.com](https://explainshell.com/)**: Command-line helper that parses complex shell commands and matches each argument to its official man page description.

## Database & SQL

- **[SQL Murder Mystery](https://mystery.knightlab.com/)**: Interactive detective puzzle game designed to teach SQL queries, joins, and database navigation while solving a crime.

## Syntax & Fundamentals

- **[regexcrossword.com](https://regexcrossword.com/)**: Puzzle game where clues are expressed as Regular Expressions, helping build and test regex comprehension.
- **[Flexbox Froggy](https://flexboxfroggy.com/)**: Interactive game that teaches CSS Flexbox positioning concepts by writing CSS code to guide Froggy and friends.

## DevOps, Linux & Cloud Native

- **[KillerCoda](https://killercoda.com/)**: Browser-based interactive environments for practicing Linux, Kubernetes, and Cloud Native scenarios.
- **[iximiuz Labs](https://labs.iximiuz.com/)**: Hands-on Linux, Docker, Kubernetes, and networking labs and interactive playgrounds.
